KRATAK ODGOVOR

Core Web Vitals su tri Googleove metrike stvarnog korisničkog iskustva: LCP (učitavanje glavnog sadržaja ≤ 2,5 s), INP (odziv na klik ili dodir < 200 ms, koji je zamijenio FID) i CLS (vizuelna stabilnost < 0,1). Na većini poslovnih sajtova u BiH problem nisu serveri nego nekompresovane slike, blokirajući CSS/JS i fontovi bez rezervisanog prostora.

Tri Core Web Vitals metrike i pragovi za 2026. godinu

Prema zvaničnoj dokumentaciji Google Search Central: Core Web Vitals, Google ocjenjuje stvarno iskustvo posjetilaca na mobitelu i desktopu kroz tri praga na 75. percentilu posjeta. Dobar rezultat na sve tri metrike podržava i klasično rangiranje i podobnost za Google AI Overviews.

Zašto je INP zamijenio FID i šta to znači za mobilne korisnike

Za razliku od starog FID-a koji je mjerio samo prvu interakciju, Interaction to Next Paint (INP) mjeri najsporiji odziv tokom cijele posjete — otvaranje menija, filtriranje proizvoda u web shopu ili klik na kontakt formu. Na slabijim telefonima u BiH teški page-builderi i neoptimizovani skripti lako prelaze 400 ms, zbog čega posjetilac misli da dugme ne radi i napušta stranicu.

Kada je dovoljna Speed optimizacija od 99 KM, a kada treba redizajn

Ako je struktura stranice dobra, a koče je slike, fontovi, keširanje i redoslijed učitavanja skripti, jednokratna Speed optimizacija (od 99 KM) rješava problem uz izvještaj prije i poslije. Ako je sajt građen na zastarjelom šablonu s desetinama konfliktnih dodataka, dugoročno je isplativiji čist redizajn web stranice ili detaljna provjera brzine uz besplatnu X Signal analizu.

Česta pitanja

Da li je PageSpeed Insights ocjena od 100 obavezna za dobar SEO?

Ne. Google koristi stvarne Core Web Vitals pragove (LCP ≤ 2,5 s, INP < 200 ms, CLS < 0,1), a ne samu laboratorijsku ocjenu od 0 do 100. Ipak, laboratorijski test u PageSpeed Insights jasno pokazuje šta usporava mobilni prikaz.

Koliko košta ubrzanje postojeće web stranice?

Kod Digital X jednokratna Speed optimizacija kreće od 99 KM uz mjerenje prije i poslije intervencije, dok se složeniji zahvati na web shopovima ili custom aplikacijama procjenjuju nakon pregleda.

Zašto je mobilni rezultat uvijek lošiji od desktopa?

Mobilni test simulira sporiji procesor i 4G mrežu, pa teške slike, neiskorišteni JavaScript i fontovi mnogo jače usporavaju telefon nego desktop računar.
