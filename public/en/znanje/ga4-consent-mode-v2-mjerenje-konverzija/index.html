GA4, Google Consent Mode v2 and real conversion tracking for BiH and DACH businesses

SHORT ANSWER

Google Analytics 4 (GA4) and Google Consent Mode v2 let businesses in BiH serving domestic and EU/DACH buyers measure real inquiries, calls and orders while respecting cookie consent. Mark form submissions, phone/WhatsApp clicks and purchases as Key Events and pair them with Search Console and Meta CAPI.

Consent Mode v2 signals and GA4 Key Events

Under Google Tag Platform: Set up consent mode, Consent Mode v2 governs ad_storage, analytics_storage, ad_user_data and ad_personalization. Following Google Analytics Help: About key events, mark only genuine business actions (generate_lead, phone/WhatsApp clicks, purchase) as Key Events and run a baseline check via free X Signal audit.

Frequently asked questions

Does a BiH business need Consent Mode v2?

If you receive visitors from Croatia, Germany, Austria or Switzerland or run Google Ads, Consent Mode v2 protects measurement accuracy and EU compliance.

What is the difference between a regular event and a Key Event in GA4?

A regular event logs any interaction, while a Key Event marks high-value business outcomes such as a submitted lead, call or purchase.
