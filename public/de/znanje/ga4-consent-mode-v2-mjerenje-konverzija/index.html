KURZE ANTWORT

Google Analytics 4 (GA4) und Google Consent Mode v2 ermöglichen Unternehmen in BiH mit lokalen und EU-/DACH-Kunden, echte Anfragen, Anrufe und Bestellungen datenschutzkonform zu messen. Markieren Sie Formularabsendungen, Telefon-/WhatsApp-Klicks und Käufe als Schlüsselereignisse (Key Events) und verknüpfen Sie diese mit Search Console und Meta CAPI.

Consent Mode v2 Signale und GA4-Schlüsselereignisse

Gemäß Google Tag Platform: Consent Mode einrichten steuert Consent Mode v2 ad_storage, analytics_storage, ad_user_data und ad_personalization. Laut Google Analytics Hilfe: Über Schlüsselereignisse sollten nur echte Geschäftsaktionen (generate_lead, Telefon-/WhatsApp-Klicks, purchase) als Key Events markiert werden (kostenlose X Signal Analyse).

Häufige Fragen

Braucht ein Unternehmen in BiH den Consent Mode v2?

Wenn Sie Besucher aus Kroatien, Deutschland, Österreich oder der Schweiz erhalten oder Google Ads schalten, schützt Consent Mode v2 Messgenauigkeit und EU-Konformität.

Was unterscheidet ein normales Ereignis von einem Key Event in GA4?

Ein normales Ereignis erfasst jede Interaktion, während ein Key Event geschäftskritische Ziele wie eine gesendete Anfrage, einen Anruf oder einen Kauf markiert.
