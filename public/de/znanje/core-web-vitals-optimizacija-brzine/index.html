KURZE ANTWORT

Core Web Vitals sind Googles drei Kennzahlen für reale Nutzererfahrung: LCP (Hauptinhalt ≤ 2,5 s), INP (Reaktionszeit auf Klicks < 200 ms, Nachfolger von FID) und CLS (Layout-Stabilität < 0,1). Auf den meisten Unternehmenswebsites bremsen unkomprimierte Bilder, blockierendes CSS/JS und fehlende Bildmaße stärker als der Server selbst.

Core Web Vitals Schwellenwerte und wichtigste Korrekturen 2026

Laut Google Search Central: Core Web Vitals bewertet Google reale Felddaten am 75. Perzentil für Mobilgeräte und Desktop. Gute Werte unterstützen klassische Rankings sowie Google AI Overviews, während Interaction to Next Paint (INP) jede Interaktion während des Besuchs misst.

Häufige Fragen

Ist ein PageSpeed-Score von 100 für SEO Pflicht?

Nein. Entscheidend sind die realen Core-Web-Vitals-Schwellenwerte (LCP ≤ 2,5 s, INP < 200 ms, CLS < 0,1), nicht ein Laborwert von 100.
